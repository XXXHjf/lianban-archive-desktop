# 当日梯队：行业与标签筛选

2026-10-30，用户选择局部设计稿第1版。本次只调整当日梯队的行业/标签视图，不推广其他业务页布局。

主任务：先看当日各高度的股票，再按题材缩小范围，预览并研究个股周期。

首屏保留日期与实际状态、涨停/连板/最高/首板统计、股票预览与研究入口。正文层级改成“高度 → 唯一股票 → 行业与标签”，删除行业根节点与子标签反复展开股票的默认布局，不指定或写入所谓主标签。

顶部搜索选择器可选任意当日标签，显示完整父子路径；常用根标签按最高板数、股票数量及既有标签顺序排列。单选标签，包括其后代。股票行显示最多4个末级标签，其余通过“+数量”打开全部标签；鼠标停留可读完整路径，点击标签切换筛选。空标签股票仍在全部列表中。

本日数据请求保留原v1接口，ST/创业板排除继续由服务端处理；取得整天结果后在前端应用标签与精确板数。股票与所有计数以代码去重，板数栏显示所选题材的整天分布，头部统计显示当前题材与精确板数范围。停牌高度另列，不计入当日涨停数量。日期、选股请求代次、盘中刷新逻辑继续保留。

行业筛选使用独立URL参数`daily_tag`，和标签管理的`tag`区分；前进/后退及从个股返回可恢复选择。地区、拼音、代码模式不应用行业标签筛选；切回行业模式恢复上次标签。

## 状态与响应式

- 加载：原骨架与日期加载状态，数据尚未到达时标签选择器和常用标签禁用。
- 空态：区分未收录日期与筛选无匹配；后者提供“查看全部记录”，清除标签/板数/排除条件。
- 错误：原读取错误与重试继续保留；失败不显示成空市场，不把旧结果放到新日期下。
- 成功：直接显示筛选结果与真实数量，不新增常驻说明或成功横幅。
- 禁用：日期边界、无日期、标签加载中和能力受限条件保留。
- 窄屏：标签栏允许换行，股票标签在身份下方；原周期抽屉及关闭回焦继续使用。
