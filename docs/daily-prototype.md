## 设计目标与首屏三件事

主任务：看选定交易日的梯队，选择股票研究当前/最近周期。

1. 当前状态：日期、归档/暂定/覆盖异常、来源与截至时间。
2. 关键数据：当前筛选统计、最高梯队与实际股票，不再先经过介绍/搜索/筛选/四卡的大面板堆叠。
3. 下一步：股票名称直接打开完整档案；独立“预览”在桌面右侧/窄屏面板展示周期及研究按钮。

层级：任务状态与梯队身份 → 分组股票与周期摘要 → 完整资料、证据、编辑工具。蓝色实心主按钮为研究操作；常用视图切换、刷新与管理工具保持次级。

## 变化与功能等价

| 功能 | 原入口 | 样板入口/交互 | 保留与检查 |
|---|---|---|---|
| 日期、前后有效日、最新 | 独立查询面板 | 紧凑日期栏 | 保留URL与有效日导航；边界禁用；无效日期不自动滚成另一天 |
| 股票搜索、最近查看 | 独立大搜索面板 | 顶栏搜索与“最近” | 保留名称/代码/首字母、六位代码Enter、最近记录；补可访问名称 |
| 统计与数据口径 | 四卡/长说明 | 一行统计、日期状态、来源展开 | 仍用原API数值；筛选后标明范围；缺失不显示为真实零 |
| 行业/标签、地区、拼音 | 四种分组radio | 三入口常驻 | 沿用dailyGroups/subgroups；跨组关系和原排序不改 |
| 代码分组、完整对照 | 常驻代码入口与默认矩阵 | 更多菜单 | 代码连续6→1位匹配保留；完整二维矩阵可横向滚动 |
| 精确板数、ST/GEM | 多行常驻控件 | 板数栏＋可展开筛选 | 保留查询参数、清条件与作用域摘要 |
| 股票身份、备注/标签/股东 | 每张卡全部平铺 | 紧凑行＋预览资料/工具菜单 | 原有工具和保护协议保留；窄屏先关预览再打开编辑器 |
| 当前/最近周期、逐轮竞争 | 进入个股后纵向查找 | 新增只读预览，进入现有完整档案 | 使用真实/api/stock；明确档案截至日，不能冒充所选历史日状态；旧请求不能覆盖新股票 |
| 最新日涨停标记 | 历史股票卡高亮 | 日期明确的行内状态 | 保留旧逻辑；盘中暂定不沿用昨日高亮 |
| 停牌保留高度 | 默认独立面板 | 停牌摘要与展开明细 | 原ArchiveCard明细仍可读；保留高度与当日最高、涨停家数分开 |
| 标签管理捷径 | 每组＋ | 组/子组“管理标签”菜单 | 精确进入原标签页；只读隐藏写入口 |
| 大量分组与股票 | 默认全量矩阵 | 每高度先显示6组、每子组先12行，明确展开全部 | 不删除尾部；首板默认有实际股票；展开入口与去重计数明确 |
| 公告/站内信/说明/外链 | 顶栏/侧栏 | 继续保留；完整范围在说明中 | 桌面站内信出现条件不改；平板可展开导航，手机关闭导航不可聚焦隐藏内容 |
| 刷新/自动更新/前后退 | 旧全局与日页逻辑 | 保留原轮询与参数导航 | 局部错误不冒充空市场，切日清掉旧结果和选择 |

完整矩阵仍用原卡片内容，属于可选证据/对照能力；样板默认正文已改为高度优先的非空分组，非旧矩阵换皮。

## 人工验收建议

打开样板后，先用3秒说出日期/状态、最高梯队、下一步入口。再切换地区/拼音，预览一只股票，进入完整档案后返回；用更多打开完整对照；用筛选查看条件摘要。在窄窗口验证三个分组入口和预览关闭回焦。
