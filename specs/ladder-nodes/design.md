# 梯队节点设计

## 已确认需求

前交易日唯一最高板是唯一自动锚定，不设置最低高度，并列时不生成。锚定股当日仍涨停则不生成；收盘未涨停时，开盘价≤昨收为低开节点，绑定当天二板中前日首板成员；否则为断板节点，绑定当天首板。爆量和特殊节点手动选择已确认日期、梯队及名称创建。

节点只跟随出生时的成员，连续交易日涨停且板数逐日增加才保留，断板退出且不因反包恢复。完整交易日缺失时暂停判定，盘中不确认成员淘汰。节点最后一个成员退出即不再出现在梯队，历史事实保留。

允许从查看日删除整个节点或具体股票的一个节点；此前日期保留，删除日及以后隐藏，自动刷新不得恢复。普通题材标签不受影响。所有计算按所查看日期进行，不引用未来的淘汰信息。

## 设计与数据

新增独立 `lianban.nodes` 模块和主库 v3 增量迁移：节点、出生成员、按生效日的手工排除、锚定股开盘证据、自动识别状态。自然淘汰由确认涨停事实投影，不物理删除历史。固定节点身份使重复运行幂等；开盘证据校验日期、代码、正价格并保存来源及原始路径。读取接口无来源请求。

开盘优先复用同日腾讯行情字段，其次取未复权日K的真实开盘和该日涨跌额推导昨收；不使用09:30分钟价冒充开盘。来源不可用时保留待判定状态。自动任务在服务启动和归档完成后运行，首轮处理最近20个确认交易日，历史日期可显式补识别；成功缓存复用，失败后续重试。

## 界面规范（Web / Operate）

用途：每日复盘时记住梯队所处节点及其来源。采用现有实用型工作台风格，沿用本地 Noto Sans SC 字体、蓝色操作按钮、白色背景和灰色说明。节点颜色为 #92400e / #fff7ed，边框 #fed7aa。沿用现有768/1200断点、页面宽度与4px间距尺度，不引入新页面或外部字体。

所有梯队使用相同板数列宽；节点放在股票内容区表头上方的横向提示条中，多个节点自动换行，不改变股票、标签及操作列的横向位置。股票标签区优先显示全部节点，再显示其他状态和题材标签。点击打开节点记录抽屉，显示出生日期、类型、锚定股、证据、原始成员和所选日有效成员。默认记录截至所选日，失效节点只在抽屉中出现，不污染梯队。添加节点对话框显示日期、板数、名称及成员数量。股票提供携带日期和代码的分时跳转，主板以外沿用分时能力限制。
