## Windows 下载和启动

支持 **Windows 10/11、x64 电脑**，使用 Edge 或 Chrome。

1. 下载[最新版本的安装包](https://github.com/x107108/lianban-archive-desktop/releases/latest)，将压缩包完整解压到一个你可以写入的文件夹；也可以在本仓库点击 **Code → Download ZIP** 或用 Git 克隆。不要直接在压缩包内双击文件。
2. 双击 **install.cmd** 完成安装。运行环境、固定版本依赖、字体和初始档案均已随仓库提供，安装过程无需联网、管理员权限或修改系统 PATH。
3. 双击 **start_demo.cmd**，浏览器自动打开本机网站。

默认地址是 `http://127.0.0.1:8765`。端口被其他程序占用时，会自动选择后续空闲端口并打开正确地址。再次双击启动只打开本项目已有页面，不会连接到其他项目；双击 **stop_demo.cmd** 只停止当前这份共享版。

遇到错误可运行 **verify.cmd** 检查文件；启动日志在 `data/server-error.log`。已下载项目在磁盘上的安装空间建议预留 300 MB 以上，历史数据与原始来源缓存会随使用增加。

## 功能与页面

保留源版本的日期和个股查询、历史周期、逐轮竞争、同日关系、对比排序、拼音/代码/行业/省份分组、ST/创业板筛选、最新日筛选、吸顶查询和筛选栏、标签编辑、黑名单、备注、公告及站点链接显示，以及自动采集和来源校验。字体及标题图片自托管，界面不依赖外部 CDN。

源版本的全部应用模块和网页资源保持逐字节一致，清单在 `SOURCE_BASELINE.json`；安装和启动封装单独放在 `setup_shared.py`、`desktop.py`、`launcher.ps1`，不替换网站业务与 UI。`verify.cmd` 会核对程序、资源及分发文件的 SHA-256。

界面会按窗口宽度响应式排版；比较显示效果时请使用相同的浏览器缩放比例和窗口尺寸。浏览器最近查询、筛选和滚动区高度是每台电脑独立保存的个人设置。

## 初始数据与个人记录

内置去除个人记录的历史事实档案，日期及数量见 `resources/archive-seed.sqlite3.json`。安装后不必先等待多年数据采集，就能查询已包含的历史。数据库首次安装解压到 `data/archive.sqlite3`；之后每个人独立使用自己的数据。

初始档案不包含作者个人标签、黑名单、备注、运行日志、上游原始响应、第三方涨停原因文字、完整公司地址或私人配置。这些功能仍完整可用，由使用者自行填写。股票事实、行业、省份、停牌及历史交易日记录保留；缺口、来源差异与统计口径仍由页面如实显示。

联网后，启动的网站沿用源版本的自动更新规则。电脑关闭、程序停止或上游暂不可用时，不会持续采集；已有档案仍可查询，下次启动后按规则补充。第三方来源变化可能影响以后采集的可用性，不影响已随项目提供的页面和历史库。

## 同步更新与备份

从 **2026.10.20.1** 起，右上角增加“站内信”。联网运行时在后台检查共享版正式发布消息，有新版时显示未读标记和“查看更新”提示；站内信可查看更新说明、打开官方下载页，点击“检查更新”也可手动重试。无需 GitHub 账号。已读状态保存在本浏览器，其他电脑独立记录。

自动检查正常间隔为一小时；联网失败会保留已有消息并稍后重试，不影响本地查询。此功能只提示新版，不替用户安装或覆盖个人数据库。首发版 `2026.10.20` 没有检查功能，已安装首发版的人需要手动升级一次。站内信使用共享版发布消息，不跟随私有测试版的每次代码备份触发。

Git 用户可在停止本项目后执行 `git pull --ff-only`，再运行 `install.cmd`。ZIP 用户可先停止项目、备份原目录，再把新版解压为独立目录；需要延续个人记录时，在停止旧版后用 `backup_db.py` 生成一致性快照，再将快照复制到新版的 `data/archive.sqlite3`。

重新安装只在运行库不存在时导入初始数据，**不会覆盖已有数据库、标签、黑名单和备注**。不要把自己的 `data/`、`.runtime/` 或密钥提交到 GitHub，也不要把新版初始库直接覆盖到使用中的库。

## 其他系统与开发

捆绑的一键安装仅用于 Windows x64。macOS/Linux 开发者可使用 Python 3.10+，创建虚拟环境并安装 `requirements.txt`；将 `resources/archive-seed.sqlite3.gz` 解压到 `data/archive.sqlite3` 后运行 `python app.py`。这些系统不属于本次 Windows 一键安装的验收范围。

测试需要开发环境中的 Python，以及用于前端逻辑测试的 Node.js；普通使用者不需要 Node.js。首次发布的安装及功能验收结果见 [VALIDATION.md](VALIDATION.md)。
